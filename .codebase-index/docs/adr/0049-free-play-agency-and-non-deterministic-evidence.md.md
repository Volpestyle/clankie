# docs/adr/0049-free-play-agency-and-non-deterministic-evidence.md

Free play: the model chooses each GBA action,
dispatched through the same EnvironmentRuntime
that refuses scripts — changing who decides,
never how actions are authorized. Determinism is
replaced as evidence by legality, causal linkage,
bounds, and progress metrics.

Long and empirical; read for the measured design
findings: vision + decoded state both matter;
honest effect diffing (moved / blocked / turned —
a turn is not a wall); menu screens own the
d-pad; bounded `repeat` bursts; his own
scratchpad notes; objective vs intent split (the
biggest win); model choice dominates harness
tuning; volition built but unused (resolved later
by ADR 0056).
