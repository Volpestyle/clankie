# docs/adr/0095-discord-system-actors.md

`discord.systemActorUserIds` is the deny-by-default
allowlist whose authenticated Discord text turns
receive the operator's pi machine tools. It is
separate from DM ownership and ambient command
authority, reloads per turn, and never applies to
shared durable voice sessions.

The tools list is the boundary: unlisted turns
never see bash/read/edit/write. Herdr leadership
reuses those tools and the CLI rather than adding
bespoke captain tools; mail remains operator-only.
