# docs/adr/0088-a-screenshot-is-something-he-showed-you.md

Widens ADR 0085's attachable-media boundary:
browser screenshots (`browser/` refs) ride his
reply exactly as generated images do, on the same
provenance argument — only the governed browser
host writes there, refs are hash-bound, and he
cannot forge or write one.

Read for the harvest change (walk the turn's tool
results and let the schema refine be the
authority check — never tool names, never model
text) and the invariant repair: the shell
scratchpad moved out from under the attachment
root, with a fail-loud nesting check. Accepted
cost: any page his logged-in profile can render
now has a one-call path into a room; the shell's
lack of egress carries more weight.
