# docs/adr/0098-user-session-watches-discord-shares.md

The opt-in lab user-session body watches Discord
shares through an external AGPL ClankVox sidecar;
the Apache repository keeps only its IPC client.
`discord.activeBody` selects bot or user session,
and the launcher starts exactly one mouth.

The user body owns OP20 watch and sampled JPEG
stills; `observe_share` pulls the latest governed
artifact while realtime receives only an existence
briefing. Missing ClankVox preserves metadata but
makes pixels unavailable; live receipts prove the
transport path.
