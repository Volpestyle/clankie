# branding

Public web-ready Clankie marks for the README
and OSS surfaces — deliberately pixel art. Three
PNGs plus a README: clankie-logo-512.png (square
mark used in the README header),
clankie-logo-512-alpha.png (transparent
reference for generated media), and
clankie-banner.png (wide lockup with wordmark).

Product pixel art, high-res masters, and the
garden sprite pipeline live in the private
clankie-app repo, not here. When scaling the
marks, use integer ratios and never anti-alias —
the pixel edges are intentional.
