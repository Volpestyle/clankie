# apps/vox/THIRD_PARTY_NOTICES.md

Engineering inventory for native components bundled or statically linked by Vox: libopus, OpenH264, libjpeg-turbo, and davey/OpenMLS, with exact versions delegated to `Cargo.lock`. It separately names runtime-only host programs FFmpeg, libx264, yt-dlp, the shell, and sed; this is not presented as a complete SBOM.
