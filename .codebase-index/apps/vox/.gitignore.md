# apps/vox/.gitignore

Package-local ignore rules cover `/target`, `.DS_Store`, `node_modules/`, `dist/`, and `*.tsbuildinfo`. The final `apps/docs/public/llms*.txt` pattern is also relative to `apps/vox`, so it targets a nested `apps/vox/apps/docs/public` path rather than the repository-level docs tree; source, manifests, and `Cargo.lock` remain visible.
