# apps/discord-user-session/src/index.ts

Process-global lab-body composition. It resolves public settings and brokered bearers, runs ordered owner-opt-in admission before materializing the user token, then builds the minimal gateway, shared text ingress, presence session, optional realtime voice/music, Go Live discovery/watch/publish controller, and loopback service-control server.

`joinUserSessionVoice()` is operator/body driven because a user account has no slash commands. Raw stream packets feed discovery, ClankVox decodes watched shares into service reports, and the same controller publishes a URL or local activity PNG when this body is the mouth. Refusal and media lifecycle evidence lands in an absolute content-free receipt log.

Shutdown stops watch/publish/music/control, leaves voice, closes adapters/gateway/presence, and writes one stop receipt.
