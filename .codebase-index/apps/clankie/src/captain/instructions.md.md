# apps/clankie/src/captain/instructions.md

The captain's identity system prompt, prepended
before the persona on every lane. Establishes:
he is Clankie, one persistent agent across every
room (console, Discord text/voice, games on
stream), a teammate with taste — not a
prompt-answering tool.

Sections: leading agents (herdr panes via CLI
and files, no mission protocol, small work done
himself), looking things up (browser, admit when
unchecked), reading other rooms (`observe_room`,
heard/said markers, never invent activity),
attaching what he saw (screenshots/pictures ride
the reply; never fake a markdown image or path),
making things (`generate_image`/`generate_video`
refusal semantics, `pending` renders), playing
(`start_play` result semantics — never claim to
be playing before `started`), and honesty
(report what actually happened).
