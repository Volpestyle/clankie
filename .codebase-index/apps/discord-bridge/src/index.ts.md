Messages pass existing allowlists, optionally feed `possessorRoomText`, and submit one captain turn; voice join/leave runs through `executeVoicePresenceIntent` so fresh gateway state and body policy choose the target. The loopback control server executes host-grounded music, reaction/thread, and watch actions for service tools.

Receipts contain lifecycle/latency scalars only and feed readiness/live-proof plus idle leave. Signal shutdown stops catch-up/control, voice/music/listeners and presence exactly once before appending the stop receipt.
