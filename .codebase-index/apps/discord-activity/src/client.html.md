# apps/discord-activity/src/client.html

Self-contained Discord activity viewer: a pixelated game canvas, live/idle state, and lower third separating objective/thought from next action/observed effect. The responsive page also exposes compact presentation controls without loading an application framework.

Its inline module connects through `/.proxy/frames`, sequence-fences base64 PNGs, supports the older free-form overlay shape, distinguishes an ended session from a dropped socket, and reconnects once per second.
