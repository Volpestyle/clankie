# .oxfmtrc.json

Formatter config for oxfmt (`pnpm fmt` /
`fmt:check`): 110-column width, 2-space indent,
semicolons, double quotes, trailing commas.
Ignores generated trees (artifacts, .data, .eve,
model-registry data) and — deliberately — the
frozen fixture
scenarios/minecraft/collect-craft-place/v1/
scenario.yml, whose exact bytes are part of its
hashed identity and must not be reformatted.
