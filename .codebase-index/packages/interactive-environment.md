# packages/interactive-environment

Provider-neutral Zod contracts for generic environment lifecycles, the active GBA body, Discord presence, rendered surfaces, activity observation, and play sight. Minecraft and PokeMMO are not local profiles; PokeAgent MMO enters Clankie through its external MCP world instead.

- `package.json` — contract dependencies and scripts.
- `README.md` — contract, trust, telemetry, and profile guidance.
- `src/` — environment and retained surface/profile schemas.
- `test/` — schema invariants and cross-profile rejection tests.
- `tsconfig.json` — TypeScript configuration.
