# packages/media-connector

Versioned boundary for local image/video generation through configured providers. It validates provider inputs/results, writes bounded artifacts safely, and leaves posting a generated artifact to the service's presence policy.

- `package.json` — connector dependencies and scripts.
- `README.md` — provider, artifact, and responsibility guide.
- `src/` — connector contracts and provider adapters.
- `test/` — adapter and artifact-safety tests.
- `tsconfig.json` — TypeScript configuration.
