# packages/protocol

Dependency-light Zod schemas and types that cross Clankie process and trust boundaries. It defines identities, lanes, events, operator conversations, Discord actions/evidence, embodiment, memory, media, pairing/devices, and service contracts without implementation dependencies.

- `package.json` — protocol metadata and Zod dependency.
- `src/` — canonical schema/type module.
- `test/` — schema and invariant tests.
- `tsconfig.json` — TypeScript configuration.
