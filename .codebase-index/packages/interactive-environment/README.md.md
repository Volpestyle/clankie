# packages/interactive-environment/README.md

Prose statement of the package's contract rules:
closed bounded semantic-event payloads with raw
telemetry exiled to artifact references; strict
provider-profiled v2 session/lease bounds with v1
dual-read (PokeMMO never reuses Minecraft
vocabulary); the clankie service stays
authoritative — models get no credentials, cannot
mint leases or widen the action catalog; gameplay
tools only in the active gameplay lane; the
PokeMMO live boundary is observation/coaching
only; and the ActivityObservation self-observation
read contract (selfAuthored vs runnerObserved,
digest-only framebuffer).
