# integrations

Concrete game-related integrations kept outside the shared contracts. GBA is Clankie's active embodied game world; the Minecraft package only verifies a private Paper server build and is not a Mineflayer control surface.

- `gba-emulator/` — pinned headless mGBA integration for FireRed and Emerald play.
- `minecraft-paper-verifier/` — local Paper artifact verification utility.
