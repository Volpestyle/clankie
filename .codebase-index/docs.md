# docs

Current architecture and operating documentation plus durable architecture decisions. Operational truth lives in the architecture, credentials, media, app, and package guides; ADRs preserve rationale and link to current guidance where implementation has evolved.

- `adr/` — architecture decision records and their maintenance conventions.
- `architecture.md` — current one-service system and trust-boundary map.
- `credentials.md` — credential ownership, broker IDs, and safe setup.
- `diagrams/` — editable tldraw sources and retained binary exports.
- `discord-media.md` — voice, music, Activity, Go Live, and share-watch operating guide.
