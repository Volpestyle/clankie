# .gitignore

Ignores the usual build/runtime debris
(node_modules, dist, .turbo, .data, logs, .env*,
macOS/Xcode leftovers, eve framework .eve/ and
.workflow-data/ dirs) plus a carefully carved
artifacts policy.

The artifacts rules: nested **/artifacts/ dirs
are fully untracked, but the root /artifacts/
re-includes /artifacts/evals/ so committed gate
scorecards survive (a VUH-826 ruling), while
transcript/log-bearing eval evidence
(herdr-harness, real-workers, m1-exit-gate,
per-repetition streams) stays local. Self-build
commits exactly three scorecard files. One log
exception: docs/testing/**/evidence/*.log is
tracked.
