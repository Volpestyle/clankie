# integrations/gba-emulator/test/select-menu-entry.test.ts

Tests `select_menu_entry` against scripted
menu cores built to control the stops: cursor
walked and confirmed in vertical lists and XOR
2x2 battle grids, and honest endings when the
menu closes, the cursor stalls, budgets run
out, an entry id is unknown, a bag window has
scrolled, or the naming screen (typed, not
selected) is targeted.
