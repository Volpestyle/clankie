# VUH-1659: one memory tool

[Issue](https://linear.app/vuhlp/issue/VUH-1659/one-simple-memory-tool-write-search-edit-forget).
Implementation branch: `feat/vuh-1659`, based on `origin/main` at `9a0589ca`.

## Result

- One `memory` tool provides `write(text)`, `search(query)`, `edit(id, text)`, and
  `forget(id)`. Both old episode tools are absent from the actual MCP catalog.
- The host supplies source conversation, room, and visibility. Console writes
  remain private; Discord writes are shareable. Edit and forget retain the
  existing exact-source-conversation authority check, including between console
  conversations. Missing or inaccessible edits never append a replacement.
- All notes persist until forgotten. Retention shelves, quotas, automatic
  eviction, and CLI/TUI retain controls are removed. Cards rank matching terms
  first, then recency, and cap rendered text at 8,000 characters.
- Existing episode files and wire records remain readable in place. A fixture
  with 35 legacy records preserves IDs, rooms, dates, visibility, provenance,
  and legacy defaults across loading, subsequent writes, and restart. Loading
  leaves original file bytes unchanged. No live memory was opened or migrated.
- Captain instructions, shipped `this-machine` guidance, generated Claude/Codex
  instructions, operator controls, OpenAPI descriptions, and public docs describe
  the new tool. Person facts and the memory/instruction boundary are unchanged.
