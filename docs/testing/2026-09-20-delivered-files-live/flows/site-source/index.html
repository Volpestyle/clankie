VUH 1105

Delivered files

Clankie publishes chosen conversation outputs as durable file events. Authenticated clients retrieve exact bytes and open or share a protected local copy.

Delivery path

  1. PublishResolve a regular file inside the conversation workspace.
  2. StoreHash and retain bytes under the private attachment root.
  3. RetrieveAuthorize a strict POST request and return exact bytes.
  4. Open or shareUse the device system preview and share surfaces.

Boundaries

  • Workspace realpath containment and regular files only
  • 15 MiB maximum per artifact
  • Conversation and current device grant checks
  • No bearer or capability in a download URL
  • Stored hash and byte count verified before delivery
