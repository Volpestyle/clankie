Logging contains fixed phase names, duration and outcome only; no command, output, PID, pane, path or error text. Nested timings must not be summed.

A new relay launched after Mac deployment receives these changes; existing old relays work without telemetry. The probe checks for the optional telemetry method and ignores diagnostic failures, retaining its original JSON on either route. No PC update/restart or live relay steering was performed.
