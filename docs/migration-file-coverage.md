# Retained migration file coverage

This is the current settings, project and conversation proof map for
[#337](https://github.com/Volpestyle/clankie/issues/337), checked from `34b6169e3`.
The [inventory posted before code changes](https://github.com/Volpestyle/clankie/issues/337#issuecomment-6668119288)
names each conversion, its raw marker and its release evidence. The broader
[compatibility ledger](compatibility-inventory.md) retains the other domains.

**No additional migration is removed.** No supported runtime/app floor or complete
install-marker evidence has been established. A cold file, retained journal,
rollback or backup can still carry an older shape. Main/source checkouts also
produce data between published releases. P4, the proven source-only default-role
forwarder, was already removed in #879.

v0.4.9 and v0.4.11. The last is still the latest published release at this audit.
An unpublished tag is not presented as a downloadable release. A converter's
first release does not establish the oldest writer of its source shape.

the raw field, **reader by** for a conservative upper bound on acceptance, and
**unknown** where the original writer was not established. None establishes an

## What the checks establish

The new settings cases write raw legacy JSON, require reads to leave source
bytes unchanged, perform an ordinary save and open a new store. The current-shape
case keeps an explicit portal ceiling, disabled tools/peer messages and a
completed empty migration receipt. The journal cases use actual files, the
production stores and the in-process owner loop; no model or live account is used.
The remaining proofs reuse existing real-file integrations, with their original
assertions unchanged. The scoped file totals also contain existing validation
cases; they are not all counted as distinct migrations.

No live installation, other machine, app cohort or backup was scanned. This map
proves the retained readers' behavior, not that a supported installation no longer
needs them. Ownership/ceiling and pending-question paths require independent
review before this evidence change lands.
