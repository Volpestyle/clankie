01 · Local operator

Clankie works without the app.

The TUI is a complete local way to talk to Clankie. Remote access is an option, not an installation requirement.

Install and open him

Clankie currently supports Apple-silicon Macs running macOS 14 or newer.

curl -fsSL https://raw.githubusercontent.com/Volpestyle/clankie/main/install.sh | sh
clankie

Give him a model

In the console, run /auth to add a provider key or OAuth login, then /model to choose the captain model. Credentials stay in the Mac’s Keychain-backed broker.

Use the terminal you already like

The TUI can run in an ordinary terminal or inside a terminal multiplexer. The supported fleet integration is Herdr: Clankie can lead, watch, and steer its visible agent panes. Other multiplexer adapters are not currently part of the product surface. 

clankie doctor
clankie status
clankie herdr status
02 · App-enabled operator

Set up the Mac once. Carry the window with you.

Clankie still runs on your Mac. The app reaches that Mac through a narrow public doorway; it does not move your agent into a hosted cloud service.

  1. Finish the local setup

    Install Clankie, open the TUI, authenticate a model, and confirm clankie doctor.

  2. Enable remote access

    Run /gateway, choose Enable remote access, and complete the email one-time-code flow. During an invite-only beta, use the email named in your invitation.

  3. Keep the Mac available

    Run clankie autostart enable. The Mac must stay awake, online, and signed in.

  4. Pair the app

    Open the iPhone or iPad app, run clankie pair on the Mac, then scan the QR code or type its single-use code. Review the requested grants before connecting.

Hybrid

Move between the local TUI and the app. Both are windows into the same Clankie and Mac.

App-first

After setup, spend nearly all your time in Messages, fleet views, and terminal observation on iPhone or iPad. The Mac quietly remains the host.

You do not need Tailscale. App users do not copy URLs, host ids, or bearer tokens, and they do not need to understand Herdr unless they want fleet panes.

What stays where

Your Mac remains the center.

The doorway routes an authenticated device home; it is not a hosted Clankie runtime.

On your Mac

Clankie, model credentials, conversations, Herdr panes, terminal processes, and owner settings.

At the doorway

Account discovery, authenticated Mac presence, short-lived pairing routes, and request transit.

Read the privacy notice for data handling and the public network surface for the exact internet-facing routes and their access requirements.

When something feels off

Start with one truthful card.

clankie doctor reports the installation, model, credentials, optional tools, and services. 

clankie doctor
clankie status
clankie autostart status
clankie gateway status

If the diagnostic card does not resolve it, continue with Clankie support.
